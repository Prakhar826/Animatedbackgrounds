# Animated Backgrounds

**A free library of 650+ animated backgrounds for websites.**

[Visit Animated Backgrounds](https://animatedbackgrounds.me/)

Animated Backgrounds helps designers and developers find animated backgrounds for landing pages, portfolios, dashboards, and other web projects. Browse a large collection of CSS- and JavaScript-based effects, preview styles, and use the available tools to create or export background visuals.

## What's included

- **Background library:** Explore 650+ animated background effects and visual styles.
- **Studio:** Customize and experiment with background designs.
- **GIF Tool:** Create GIF versions of background visuals.
- **Developer-friendly effects:** Find backgrounds suitable for integrating into web projects.

Animated Backgrounds is an independent web resource for people building and designing websites. The goal is to make expressive animated backgrounds easier to discover, preview, and use.
