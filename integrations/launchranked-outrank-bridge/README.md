# LaunchRanked–Outrank bridge

This is an isolated Netlify Functions service. It does **not** replace, modify or host the main Animated Backgrounds website, and it does not move your existing Outrank blog.

## What this first deployment does

- Receives LaunchRanked webhook requests over HTTPS.
- Verifies the `X-LaunchRanked-Signature` header using HMAC-SHA256 and your shared signing secret.
- Responds to LaunchRanked's signed `ping` test with HTTP 200.
- Stores non-ping events in a private Netlify Blobs inbox.
- Does **not** publish articles yet. We must inspect the first real article-event payload before mapping its fields to Outrank. This avoids guessing and accidentally publishing malformed or duplicate sponsored posts.

## Create a separate Netlify site

1. In Netlify, choose **Add new project → Import an existing project**.
2. Connect GitHub and select `Prakhar826/Animatedbackgrounds`.
3. Set the **Base directory** to:
   `integrations/launchranked-outrank-bridge`
4. Leave the build command blank. The included `netlify.toml` sets the publish and functions directories.
5. Before deploying, add these environment variables under **Project configuration → Environment variables**. Set their scope to **Functions** and their deploy context to **Production**:
   - `LAUNCHRANKED_SIGNING_SECRET`: a long random value generated by a password manager.
   - `BRIDGE_ADMIN_TOKEN`: a different long random value used only to view the private inbox.
6. Deploy the new project. Do not put either secret in GitHub, this README, or `netlify.toml`.

Your existing Netlify project named `psychonauts-api` should remain untouched.

## Connect LaunchRanked

After Netlify deploys, use this URL (replace the host with your new Netlify site name):

`https://YOUR-NEW-SITE.netlify.app/.netlify/functions/launchranked`

In LaunchRanked → Settings → Publishing:

1. Choose **Webhook**.
2. Paste the URL above.
3. Paste the exact same `LAUNCHRANKED_SIGNING_SECRET` value into **Signing secret**.
4. Save the integration and click **Test connection**.

A valid signed ping should receive HTTP 200. The GET endpoint can also be opened in a browser to confirm that the service is online.

## Inspect the first real article event

Open:

`https://YOUR-NEW-SITE.netlify.app/inbox.html`

Enter the `BRIDGE_ADMIN_TOKEN` value. The page retrieves the latest 20 non-ping events from the private Netlify Blobs store. Share the event JSON for field mapping, but never share either secret.

## Finish Outrank publishing

After the actual LaunchRanked article-event shape is known, the bridge can be updated to:

- map article title, HTML/Markdown content, SEO description, cover image and source URL;
- use the Outrank API key stored as a Netlify environment variable;
- create the article on the correct Outrank product/blog;
- use a stable idempotency key and Outrank's duplicate-slug protection;
- publish or create a draft according to your preferred review process.

The Outrank API key and product ID are intentionally not included in this first version.

## Paid-link policy note

Before automating paid placements, check the marketplace terms and Google's current paid-link requirements. Paid or sponsored links should be qualified with `rel="sponsored"` (or `nofollow`) where required; a marketplace's preference for followed links does not override Google's policies.
